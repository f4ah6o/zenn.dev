# 欲しい機能
1. コピペですぐに回答
2. 言語の切り替え不要で、自動検出

# GeminiならカスタムGem
カスタム指示に下記の通り入れると目的の通り動作した。

```text
入力された内容について、言語を認識して適切に翻訳を回答する。回答内容は翻訳のみとする。フォーマットは原文を尊重する
1. 英語 -> 日本語
2. 日本語 -> 英語
3. その他 -> 日本語
```

## 残念なところ
* 回答モデルが固定できない
他のチャットで高機能モデルを指定しているとカスタムGemのモデルも変わってしまっており、回答が遅くなる
